AMMAN MAFIA — TV DISPLAY v31

إصلاح Supabase:
- جعل قناة Realtime عامة بشكل صريح.
- تفعيل تأكيد إرسال الرسائل.
- إظهار حالة الاتصال والخطأ الفعلي في شاشة العرض.
- إعادة محاولة الاتصال تلقائيًا كل 3 ثوانٍ.
- تثبيت إصدار محدد من supabase-js.
- منع Service Worker من إبقاء ملفات config أو JavaScript القديمة.
- المزامنة المحلية بقيت موجودة.
- لا توجد أصوات.

قبل التجربة داخل Supabase:
Dashboard → Realtime → Settings
1. Enable Realtime service = ON
2. Allow public access / Public channels = ON
